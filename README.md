# E-Commerce Shopping Cart System 🛒

A simple Python project demonstrating Object-Oriented Programming (OOP) through an e-commerce shopping cart.

## Features
- Create products with ID, name, category, price, and stock.
- Add and remove products from the cart.
- Display selected products.
- Calculate the total amount.
- Check product availability.
- Handle out-of-stock products.

## Technologies
- Python
- Object-Oriented Programming (OOP)

## Run the Project

```bash
python main.py
```
